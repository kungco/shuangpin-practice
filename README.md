# 双拼练习 · 小鹤方案

一个离线可用的双拼输入法练习应用。零依赖、零构建，打开即用。

## 怎么打开

> **为什么不能直接双击 `index.html`？**
> 浏览器禁止在 `file://` 协议下加载 ES 模块（CORS 限制），直接打开会白屏。
> 必须经由本地 HTTP 服务访问。下面的方式都已绕过这个限制。

### Windows（最简单）

双击仓库里的 **`启动双拼练习.bat`** —— 它会自动挑一个空闲端口起服务，
并在就绪后打开浏览器。用完关掉那个最小化的服务窗口即可。

> 如果你想让它在桌面上有个图标方便双击，运行一次 `_test/make_lnk.py` 自行生成
> （见该文件头部说明）。快捷方式不是仓库的一部分，需要在本机生成。

### macOS / Linux，或任何已装 Python 的环境

```bash
# 在仓库根目录执行
python3 -m http.server 8781
# 然后浏览器访问 http://127.0.0.1:8781/
```

Windows 上若 `python` 不在 PATH，把命令换成 `py -m http.server 8781` 即可。

### 其它方式

用 VS Code 的 **Live Server** 插件打开 `index.html` 也可以。

> ℹ️ 应用本身**零依赖、无需联网**，不做任何网络请求。
> 用本地 HTTP 服务只是为了让浏览器允许加载 ES 模块，与联网无关。
> 整个应用可以离线使用，数据全部存在浏览器本地。

## 功能

- **为什么用双拼**（内置说明页）：面向还没学过双拼的人，用「全拼 vs 双拼」
  逐字对比讲清原理（全拼 `shuang` 6 键 → 双拼 `UL` 2 键），列出六条实际好处
  （击键量、重码、肌肉记忆、手部负担、左右手均衡、跨平台可用），
  并**如实说明三个代价**（前三周会变慢、换机器不顺手、键位必须背）
  与一个四周的学习节奏建议。页面里的示例编码全部由引擎实时校验。
- **方案**：小鹤双拼。全屏键位图 + 迷你键位图实时高亮当前该按的键，
  区分声母（蓝）/ 韵母（橙）/ 零声母（绿），按对、按错、待按各有独立状态色。
- **七种模式**：键位熟悉 → 只听声母 → 只听韵母 → 声韵拆分 → 单字 → 词组 → 短文跟打，
  按常用度七档渐进。
- **卡住自动提示**（默认开启）：某个键停留 **3 秒**后，键位图上该键开始闪烁（只给位置、
  不给答案）；停留满 **6 秒**直接亮出答案。任何一次按键都会重新计时，暂停发呆不会刷出提示。
  随时按 `Tab` 可手动求助。设置页可调提示节奏（也可关闭）。
- **实时反馈**：逐键校验。按错立即提示正确键位、拆分方式与完整编码
  （例如：`都（dou），应拆为「d + ou」，编码 DZ，第 1 键（声母=d）应是 D`）。
  HUD 实时显示速度、正确率、用时、连击、进度。
- **统计与复习**：每日练习数据、历史成绩曲线（速度/正确率/字数三种指标，日/周/月可切换）、
  易错字词表、**错误热力图**（直接在键盘上标出你最常按错的键，可按全部/近 30 次/近 10 次
  切换范围）。易错项按「错误次数 × 时间衰减 × 掌握惩罚」加权排序，可一键生成针对性复习题。
- **体验**：时长/题量可自定义（含不限），随时暂停/继续，中断后可续练（现场存本地），
  设置与进度持久化，数据可导出/导入 JSON。

### 关于「提示」与正确率的口径

提示本质上是引擎替你想出了答案，所以**提示过的字符不计入独立正确率的分子**。
HUD 上的「正确率」是表面值（按对的键都算），结算页会额外给出**独立正确率**
（剔除依赖提示的字符）与**提示次数**。这样「等提示再按」不会把成绩刷满，
两个指标的差值正好反映你对键位的真实掌握程度。


## 关于键位（几个容易踩的点）

小鹤双拼里这几条规则和很多教程的简写不一样，本应用按官方标准实现：

1. **每个音节恒为 2 键**（这是双拼的基本前提）
   - `zhang` → `V` + `H`（`V` 是声母 zh，`H` 是韵母 ang）
   - `zheng` → `V` + `G`
   - `shu` → `U` + `U`、`zhui` → `V` + `V`（同一个键可以按两次，各自含义不同）
2. **`zh` / `ch` / `sh` 各占一个键**，只影响音节的**第一键**
   - `zh` → `V`、`ch` → `I`、`sh` → `U`
   - 它们**不会额外占用 H 键**。`zhang` 第二键的 `H` 表示的是韵母 `ang`，
     和声母没有任何关系。
   - 常见误解是把 `zh` 写成「`Z`+`H`」两键，那是错的。
3. **零声母音节也按 2 键算**：`a`、`o`、`e` 等单韵母，
   首字母本身就是韵母键，按两次即可（`a` → `AA`、`o` → `OO`）。
   复韵母直接打：`an` → `AJ`、`ang` → `AH`、`ai` → `AD`。
4. **`ü` 归一化为 `v`**：`jue/que/xue/yue` → `ve`；`ju/qu/xu/yu` → `v`。

|---|---|---|---|---|---|
| Q | iu | A | a | Z | ou |
| W | ei | S | ong / iong | X | ia / ua |
| E | e | D | ai | C | ao |
| R | uan / er | F | en | V | ui / v |
| T | ve / ue | G | eng | B | in |
| Y | un | H | ang | N | iao |
| U | u | J | an | M | ian |
| I | i | K | ing / uai | | |

## 目录结构

```
index.html                入口
启动双拼练习.bat           一键启动（起服务 + 开浏览器）
assets/style.css          样式
src/main.js               应用装配、视图渲染、键鼠事件
src/core/scheme.js        小鹤方案引擎（拆分 / 逐键校验 / 键位数据）
src/core/engine.js        练习引擎（状态机 / 计时 / 统计 / 停留提示）
src/core/questions.js     七级出题
src/core/tokenizer.js     短文分词 + 拼音标注（动态规划）
src/core/storage.js       本地存储（含降级与配额恢复、键维度错误统计）
src/core/stats.js         历史汇总 / 曲线数据 / 易错排序 / 错误热力图（P90 归一化）
src/data/pinyin.js        题库：1107 字 / 299 词 / 45 篇短文
src/ui/keymap.js          SVG 键盘渲染（含热力图层、提示闪烁）
src/ui/chart.js           Canvas 手绘曲线（无图表库）
_test/                    开发期自检脚本（可删）
```

## 数据说明

题库内置 **1107 个单字 / 299 个词组 / 45 篇短文**，按常用度分七档
（高频字 → 常用字 → 中频字 → 进阶字 → 书面字 → 扩充字 → 词组配套）。

最后一档「词组配套」专门用于补齐词组语料：确保**词组里出现的每个字
都能在单字模式下单独练到**，不会出现「只在词组里见过、从没单独练过」的字。

所有数据存在浏览器 `localStorage`（命名空间 `shuangpin.v1`）。
隐私模式或配额满时会自动降级为内存存储，应用仍可正常使用。

在「设置」页可以导出 JSON 备份，也可以导入合并。
