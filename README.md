# 双拼练习 · 小鹤方案

一个离线可用的双拼输入法练习应用。零依赖、零构建，打开即用。

## 怎么打开

> **为什么不能直接双击 `index.html`？**
> 浏览器禁止在 `file://` 协议下加载 ES 模块（CORS 限制），直接打开会白屏。
> 必须经由本地 HTTP 服务访问。下面的方式都已绕过这个限制。

### Windows（最简单）

双击仓库里的 **`启动双拼练习.bat`** —— 它会固定使用 `8781` 端口起服务，
并在就绪后打开浏览器。重复启动会复用已验证的服务；如果端口被其他程序占用，
会提示关闭占用程序，避免切换地址后看不到浏览器中的练习记录。用完关掉那个最小化的服务窗口即可。

**不需要预先安装任何东西。** 脚本会按 **Python → Node.js → PowerShell** 的顺序
挑一个可用的来起服务，其中 PowerShell 是 Windows 自带的，所以任何一台
Windows 都能直接跑起来。设置里也不需要你手动选，脚本会自己判断。

> 如果你想让它在桌面上有个图标方便双击，运行一次 `_test/make_lnk.py` 自行生成
> （见该文件头部说明）。快捷方式不是仓库的一部分，需要在本机生成。

### macOS / Linux，或任何已装 Python / Node 的环境

任选一种起服务，然后访问 `http://127.0.0.1:8781/`：

```bash
# 在仓库根目录执行
python3 -m http.server 8781        # Python（Windows 上用 python 或 py）
node _test/serve.mjs 8781          # Node.js（零依赖）
# PowerShell（Windows 自带）
powershell -NoProfile -ExecutionPolicy Bypass -File _test/serve.ps1 -Port 8781
```

### 其它方式

用 VS Code 的 **Live Server** 插件打开 `index.html` 也可以。

> ℹ️ 应用本身**零依赖、无需联网**，不做任何网络请求。
> 用本地 HTTP 服务只是为了让浏览器允许加载 ES 模块，与联网无关。
> 整个应用可以离线使用，数据全部存在浏览器本地。

## 功能

- **为什么用双拼**（内置说明页）：面向还没学过双拼的人，用「全拼 vs 双拼」
  逐字对比讲清原理（全拼 `shuang` 6 键 → 双拼 `UL` 2 键），列出六条实际好处
  （击键量、重码、肌肉记忆、手部负担、左右手均衡、跨平台可用），
  并**如实说明三个代价**（前三周会变慢、换机器不顺手、键位必须背）
  与一个四周的学习节奏建议。页面里的示例编码全部由引擎实时校验。
- **方案**：小鹤双拼。全屏键位图 + 迷你键位图实时高亮当前该按的键，
  区分声母（蓝）/ 韵母（橙）/ 零声母（绿），按对、按错、待按各有独立状态色。
- **七种练习模式**：键位熟悉 → 只听声母 → 只听韵母 → 声韵拆分 → 单字 → 词组 → 短文跟打，
  单字可选七档固定难度，默认高频字，也可选择自适应挑战，由独立正确率和反应时间升降档。
- **能力测验**（第 8 个模式）：50 题混合卷（拆分 3 : 单字 4 : 词组 3），
  **全程无提示、无求助**——自动提示关闭、`Tab` 手动求助被禁用、迷你键位图与提示条隐藏，拆分答案与拼音悬浮提示不显示，
  按错只提醒重试，不揭示正确答案。完成至少 20 个字符后，交卷按「正确率 × 速度」给出 **0–100 综合分**与 S/A/B/C/D/E 等级。
- **卡住自动提示**（默认开启）：某个键停留 **3 秒**后，键位图上该键开始闪烁（只给位置、
  不给答案）；停留满 **6 秒**直接亮出答案。任何一次按键都会重新计时，暂停发呆不会刷出提示。
  随时按 `Tab` 可手动求助。设置页可调提示节奏（也可关闭）。
- **逐步撤掉提示**：开始前可选完整提示、只显示拼音、独立输入，或自动依次减少提示。
  自动训练每 10 个作答单元评估一次：完整提示阶段正确率 ≥90%、平均反应 ≤4 秒后进入拼音阶段；
  拼音阶段独立正确率 ≥90%、平均反应 ≤3 秒后进入独立输入。
  答案高亮、错误答案反馈、拼音悬浮会随阶段隐藏；求助仍可用，并计为辅助。
  直接展示答案完成的字符也不计入独立正确率。暂停和离线时间不参与反应时间计算。
  评估用的是**滑动窗口**（最近 10 个单元），一个手滑的样本不会把之前的好成绩一起作废；
  决策频率仍是每 10 个单元一次，不因为窗口填满就每题调档。
- **自适应挑战**：单字从第 1 档起，每 10 个作答单元评估独立正确率与平均反应时间。
  ≥90% 且 ≤3 秒升一档；<70% 或 >6 秒降一档，档位限制在 1–7。
  完整提示阶段只评估撤提示，不升难度；固定档位不受影响。
  选择自适应挑战时会将完整提示切换为逐步撤提示；如果手动改回完整提示，档位保持不变。
  新档位立即用于下一题，不限量换批和暂停续练均保留档位、阶段与未满窗口的表现。
- **键位覆盖**：先覆盖全部声母与韵母成分，再循环覆盖；每五题最多插入一题易错键强化。
  弱键由历史及本轮错误决定；暂停续练保留覆盖范围。
  强化题是插在覆盖轮次之间的额外题，不占用覆盖名额；首轮全覆盖期间不插入。
- **词组筛选**：所有词组带静态分类（日常 / 办公 / 出行 / 成语），可同时筛选二字、三字、四字。
  长度作为入门 / 进阶 / 挑战参考，不代表同长度词组一定同难度。无内容的组合不会启动练习。
  词池与随机避重队列缓存后，无需逐题扫描整份词库；每轮覆盖完再循环。
- **分模式统计**：总览、历史曲线、每日练习量可按模式查看。
  平均速度按时长加权，平均正确率按完成字数加权；曲线均值使用同一口径，
  所以那条均值线**不等于**曲线上各点的算术平均（一条 1 秒和一条 10 分钟的练习权重不同），
  差距明显时页面会写明两个数分别是什么。
  老记录若缺时长或字数，加权分母为 0，此时退回算术平均而不是显示 0 分。
  每日练习量以日报为准（成绩记录只保留最近 2000 条，日报才长期累积），
  成绩记录只用于补日报缺的天；错误热力图和易错字词继续显示全部模式的累计信息。
- **短文注音**：按词组语境标注拼音，校正「重复」「重新」「成长」等常见多音字组合。
- **实时反馈**：逐键校验。完整提示阶段按错会提示正确键位、拆分方式与完整编码
  （例如：`都（dou），应拆为「d + ou」，编码 DZ，第 1 键（声母=d）应是 D`）。
  HUD 实时显示速度、正确率、用时、连击、进度。
- **统计与复习**：每日练习量、历史成绩曲线（速度 / 正确率，可选最近 20 轮、50 轮或全部），
  易错字词表、**错误热力图**（直接在键盘上标出你最常按错的键，可按全部/近 30 次/近 10 次
  切换范围）。易错项按「错误次数 × 时间衰减 × 掌握惩罚」加权排序，可一键生成针对性复习题。
- **间隔重复复习**（SM-2 简化版）：每个易错项会记录**连对次数**与**下次复习时间**，
  无提示、未答错的独立作答每天最多推进一次；答对则间隔沿 `1 → 3 → 7 → 16 → 35 → 75 天` 阶梯前进（走完阶梯后按难度系数继续拉长，
  上限 365 天），答错则重置为 1 天并下调难度系数。复习页顶部显示「今天有 N 项到期」，
  每个条目带掌握度进度条与「还有几天」；可以只练到期项，也可以按权重补齐。
  连对够多且错误率降下来的条目会自动标记为「已掌握」，不再占用默认队列
  ——但**一旦再答错就会被撤销**，重新进入队列。
- **按键音效**（默认关闭）：用 WebAudio 实时合成，**不含任何音频文件**。
  答对是一声轻脆短音、答错是低沉短音、完成一轮是三音上行，测验分数不理想时是两音下行。
  连续答错会自动降音量（最低到 35%），避免提示音变成惩罚。设置页打开开关时会立刻
  响一声作为确认，同时完成浏览器的音频解锁。
- **无障碍与输入适配**：
  - 遵循系统「减少动态效果」设置（也可在设置页强制开/关）：开启后答错的抖动
    会换成**静态描边**提示，信息量等价但对前庭敏感的用户更友好。
  - **快捷键可配置**：看答案 / 跳过 / 暂停 / 提交四个动作都能改键或解绑。
    把 `Tab` 解绑后，它会恢复成浏览器原生的焦点导航键 —— 不再被练习页占用。
  - **读屏软件支持**：答错与进度通过 `aria-live` 区域播报（错误用 assertive 插队、
    进度用 polite 排队），并刻意**先清空再写入**以保证重复内容也能被复读。
  - **非 QWERTY 布局兼容**：作答按**物理键位**（`KeyboardEvent.code`）识别，
    所以 Dvorak / AZERTY 用户练到的是「手指实际落在哪个键」，不会整体错位。
- **体验**：时长/题量可自定义（3、5、10、20、30、50、100、200、500 题或自定义 1–5000 题，含不限量自动续题），随时暂停/继续，中断后可续练（现场存本地），
  设置与进度持久化，数据可导出/导入 JSON。暂停、切到后台及离开页面会保存现场，
  续练保留当前按到第几键，以及已答错、看过提示的状态。备份合并按来源去重计数，
  复习排期以最新作答为准，兼容旧版本备份。

### 关于「提示」与正确率的口径

提示本质上是引擎替你想出了答案，所以**提示过的字符不计入独立正确率的分子**。
HUD 上的「正确率」是表面值（按对的键都算），结算页会额外给出**独立正确率**
（剔除依赖提示的字符）、**依赖提示字数**、**错键次数**与**自动跳过字数**。
这样「等提示再按」不会把成绩刷满，两个指标的差值正好反映你对键位的真实掌握程度。

练习途中也能看见：等提示才打对的字在字形行上带**橙色虚线下划线**并标出
「不计入独立正确率」，拆分面板上同样的提示态有对应配色 —— 提示不再只是
一句「不计入分数」，而是能一眼看出是哪些字。

### 关于「能力测验」的评分口径

测验模式从引擎层硬关掉提示，所以这里**只有独立正确率这一种口径**，不存在被提示刷分的可能。
综合分满分 100，构成如下：

| 分项 | 权重 | 说明 |
|---|---|---|
| 正确率 | 70 分 | 独立正确率 × 70，即全部按对得 70 分 |
| 速度 | 30 分 | 字/分钟，40 字/分 起算，120 字/分 拿满 |
| 完成度 | 乘数 | 未答完按比例折算，中途交卷会扣分 |

速度分带一个**正确率闸门**：正确率低于 60% 时速度分只按 40% 计入，
正确率到 80% 才全额计入——避免「疯狂乱敲堆速度」。另外，有效字符数少于 20 时，
仅显示练习数据与样本不足说明，不给综合分、等级，也不记作有效成绩。

等级对照：`S ≥ 95 卓越` / `A ≥ 85 优秀` / `B ≥ 70 良好` / `C ≥ 55 及格` /
`D ≥ 40 待加强` / `E < 40 需重练`。


## 关于键位（几个容易踩的点）

小鹤双拼里这几条规则和很多教程的简写不一样，本应用按官方标准实现：

1. **每个音节恒为 2 键**（这是双拼的基本前提）
   - `zhang` → `V` + `H`（`V` 是声母 zh，`H` 是韵母 ang）
   - `zheng` → `V` + `G`
   - `shu` → `U` + `U`、`zhui` → `V` + `V`（同一个键可以按两次，各自含义不同）
2. **`zh` / `ch` / `sh` 各占一个键**，只影响音节的**第一键**
   - `zh` → `V`、`ch` → `I`、`sh` → `U`
   - 它们**不会额外占用 H 键**。`zhang` 第二键的 `H` 表示的是韵母 `ang`，
     和声母没有任何关系。
   - 常见误解是把 `zh` 写成「`Z`+`H`」两键，那是错的。
3. **零声母音节也按 2 键算**：`a`、`o`、`e` 等单韵母，
   首字母本身就是韵母键，按两次即可（`a` → `AA`、`o` → `OO`）。
   复韵母直接打：`an` → `AJ`、`ang` → `AH`、`ai` → `AD`。
4. **`ü` 归一化为 `v`**：`jue/que/xue/yue` → `ve`；`ju/qu/xu/yu` → `v`。

完整韵母键位表：

| 键 | 韵母 | 键 | 韵母 | 键 | 韵母 |
|---|---|---|---|---|---|
| Q | iu | A | a | Z | ou |
| W | ei | S | ong / iong | X | ia / ua |
| E | e | D | ai | C | ao |
| R | uan / er | F | en | V | ui / v |
| T | ve / ue | G | eng | B | in |
| Y | un | H | ang | N | iao |
| U | u | J | an | M | ian |
| I | i | K | ing / uai | | |
| O | uo / o | L | iang / uang | | |
| P | ie | | | | |

## 数据说明

题库内置 **1787 个单字 / 2247 个词组 / 100 篇短文**，按常用度分七档
（高频字 → 常用字 → 中频字 → 进阶字 → 书面字 → 扩充字 → 词组配套）。

不限量练习按小批次自动续题，直到时间到或主动结束；续练保留累计进度，题目队列只保存当前批次。单字、词组、拆分和短文优先避开近期实际见过的内容，候选用完才进入下一轮；开启易错强化后，单字和词组练习每五题最多穿插一题复习。短文题量按段落计算，不再限制为八段。能力测验保持有限题量与原有题型比例。

新增短文为本项目原创练习文本，附逐字语境拼音；拼音辅助标注工具只在开发期使用，发布内容仍可离线运行。

最后一档「词组配套」专门用于补齐词组语料：确保**词组里出现的每个字
都能在单字模式下单独练到**，不会出现「只在词组里见过、从没单独练过」的字。

所有数据存在浏览器 `localStorage`（命名空间 `shuangpin.v1`）。

### 存储降级

隐私模式（`localStorage` 完全不可用）或**配额写满**时会自动降级为内存存储：

- 降级是**读写一起切换**的 —— 写失败后立刻读，数据仍在当前会话里，
  不会出现「刚保存的成绩当场读不回来」。
- 降级**不是单向**的：用户清理出空间后再写一次，会自动恢复落盘，
  并把内存里攒下的数据一并补写回 `localStorage`。
- 内存态下「清空数据」会同时清 localStorage 与内存，避免刷新后老数据复活。
- **降级会明说**：顶栏徽标从「离线 · 本地存储」改为「离线 · 内存（配额已满）」
  并高亮，设置页的存储说明同步改口（不再声称「保存在 localStorage 中」），
  首次降级还会弹一次提示。数据在不在，要比界面上的承诺更早被看到 ——
  否则用户练完整场、关掉页面才发现全没了。恢复后徽标自动回到正常态。

### 导入合并

在「设置」页可以导出 JSON 备份，也可以导入合并：

- **历史记录**按 `id` + 时间戳双重去重后**相加**合并（上限 2000 条）。
- **每日统计由合并后的历史重新推导**，而不是两份聚合值逐字段取较大值 ——
  这样两台设备同一天各有记录时不会少算，日报与历史永远一致。
- 易错表、键位错误次数属累计量，同样相加合并；重复导入同一份备份是幂等的。
  间隔重复的调度字段（连对次数 / 间隔 / 下次到期）取**更靠前**的一侧，
  这样「在一台设备上练得更熟」的进度不会因为导入一份旧备份而倒退。
- 历史中已不存在、仅存于老备份 daily 的日期会被保留，不会被重建覆盖掉。

## 自检

应用本体零依赖，但 `_test/` 下有**七套**开发期自检脚本（不影响应用运行）：

```bash
cd _test
npm ci      # 只有 integration.mjs 需要 linkedom，按锁文件精确还原
npm test    # verify → engine → storage → a11y → launcher → training → integration
```

| 套件 | 覆盖 | 依赖 |
|---|---|---|
| `verify` | 方案正确性、题库可拆分性、键位表完整性、测验出题配比与评分 | 无 |
| `engine` | 逐键校验、推进、统计、暂停、限时、异常输入、考试模式无提示硬约束、**逐字「等提示才打对」标记** | 无 |
| `storage` | 配额降级与恢复、导入合并、日报一致性、**间隔重复排期**、设置项类型校验 | 无 |
| `a11y` | 减少动态效果、快捷键规范化与冲突校验、**Dvorak/AZERTY 物理键位**、读屏播报、**音效合成与连错降音** | 无 |
| `launcher` | 启动脚本编码前提、三级回退链、与服务端脚本的接口一致性、危险写法扫描 | 无 |
| `training` | 提示撤除、滑动窗口与决策节奏、自适应档位、键位覆盖与强化上限、词组筛选、续练状态、加权统计降级、日报回落与计时同源、大题量性能 | 无 |
| `integration` | 在模拟 DOM 中加载整个应用并驱动完整流程（含测验端到端、辅助功能接线层、**提示依赖度可见性**、**存储降级如实告知**） | `linkedom` |

`.github/workflows/tests.yml` 会用 Node 18 / 20 / 22 三个版本各跑一遍。
细节见 `_test/README.md`。
