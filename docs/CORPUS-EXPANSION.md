## 使用入口

- 自由练习 → 词组打字 → 分类选择“聊天句子”或“办公句子”，长度可选“五字以上”。
- 自由练习 → 短文跟打 → 按“文章主题”和“文章篇幅”筛选。
- 文章主题选“易错专项”后，可以进一步选择具体专项。
- 不存在的筛选组合明确显示空结果，不会悄悄改练其他材料。
- 长文在有界阅读区显示，输入时自动跟随当前字，声韵提示不再被挤到整篇文章后面。

## 数据与维护

`scripts/corpus-source.mjs` 保存原创文本和复核读音词条。`npm run corpus:generate` 使用锁定的 pinyin-pro 3.29.4 初标，再叠加复核词条，生成静态 `src/data/practice-expansion.js`。浏览器运行时不依赖该包，也不调用外部注音服务。

`docs/CORPUS-READING-AUDIT.md` 列出易混多音字的上下文和最终读音。所有新增汉字、词句与文章均检查逐字对齐、合法音节、双拼可拆分性和重复内容；生成结果可复现。

v1.9.0 补齐了原文、逐字复核注音与生成器。`src/data/context-readings.js` 保存经复核的语境修正，区分助词“地”的 de 与名词“地图/地方”的 di；`npm run corpus:check` 同时校验题库和复核表。生成器使用已复核注音，不会因注音库升级覆盖复核结果。聊天初标工具的开发依赖另在 scripts/package-lock.json 锁定。
